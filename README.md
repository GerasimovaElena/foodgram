# Foodgram

Foodgram - это веб-приложение для любителей готовить, где пользователи могут создавать, сохранять и делиться своими рецептами. Приложение позволяет пользователям добавлять рецепты в избранное, формировать список покупок и генерировать прямые ссылки на рецепты для быстрого доступа.

## Особенности
- Создание рецептов: Пользователи могут добавлять рецепты с описанием, ингредиентами и изображениями.
- Управление списком покупок: Приложение позволяет автоматически генерировать список покупок на основе выбранных рецептов.
- Избранные рецепты: Возможность добавлять рецепты в избранное для быстрого доступа.
- Генерация ссылок: Пользователи могут получать прямые ссылки на свои рецепты.
- Аутентификация и авторизация: С использованием djoser и authtoken для регистрации и управления пользователями.

## Использование
### Спецификация API
Спецификация API доступна по адресу: [https://doradog.ddnsking.com/api/docs/](http://localhost/api/docs/)

### Основные API маршруты
- `GET /api/recipes/` - Получение списка рецептов
- `POST /api/recipes/` - Создание нового рецепта
- `GET /api/recipes/{id}/` - Получение подробной информации о рецепте
- `GET /api/recipes/{id}/get-link/` - Получение прямой ссылки на рецепт
- `POST /api/recipes/{id}/favorite/` - Добавление рецепта в избранное
- `POST /api/recipes/{id}/shopping_cart/` - Добавление рецепта в корзину покупок
- `GET /api/recipes/download_shopping_cart/` - Загрузка списка покупок

### Управление избранными рецептами
Пользователи могут добавлять рецепты в избранное и удалять их с помощью маршрутов /favorite/.

### Формирование списка покупок
На основе выбранных рецептов можно автоматически сгенерировать список покупок и скачать его в текстовом формате.
